# Spec Delta

## Purpose

在旅程中管理地点（途经点/目的地）并维护其访问顺序与路线概览，支撑地点及路线规划。

## ADDED Requirements

### Requirement: 向旅程添加地点
系统 MUST 允许用户向旅程添加地点，至少包含地点名称；可选记录地址或坐标备注。

#### Scenario: 添加命名地点
- **WHEN** 用户为某旅程提交地点名称并确认
- **THEN** 该地点关联到该旅程并可在地点列表中查看

### Requirement: 维护地点访问顺序
系统 MUST 允许用户调整旅程内地点的访问顺序，并持久化该顺序。

#### Scenario: 调整顺序后查看
- **WHEN** 用户将某地点在列表中上移或下移并保存
- **THEN** 地点列表与路线概览按新顺序展示

### Requirement: 将地点关联到日程日
系统 MUST 允许用户将地点关联到旅程某一天的日程，以便按日查看要去的地方。

#### Scenario: 关联到指定日
- **WHEN** 用户将某地点关联到旅程中的某一天
- **THEN** 该日日程中显示该地点

### Requirement: 展示路线概览
系统 MUST 按地点访问顺序提供路线概览（至少展示有序地点序列）；若暂无真实路网数据，MUST 明确展示为概览而非导航结果。

#### Scenario: 多地点概览
- **WHEN** 旅程中存在两个及以上已排序地点
- **THEN** 系统按顺序展示路线概览序列

#### Scenario: 地点不足
- **WHEN** 旅程中地点少于两个
- **THEN** 系统提示需至少两个地点才能形成路线概览

### Requirement: 移除地点
系统 MUST 允许用户从旅程中移除地点；移除后该地点不再出现在地点列表、路线概览及已关联的日程中。

#### Scenario: 移除已关联地点
- **WHEN** 用户移除一个已关联到某日日程的地点
- **THEN** 地点列表与路线概览不再包含该地点，对应日日程中的关联一并清除

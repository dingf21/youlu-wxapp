# Spec Delta

## Purpose

为旅程设定出行预算与分项，记录预估与实际支出，并提供对比视图，帮助用户控制旅行花费。

## ADDED Requirements

### Requirement: 设定旅程总预算
系统 MUST 允许用户为旅程设定以人民币计价的总预算金额（非负数值）。

#### Scenario: 保存总预算
- **WHEN** 用户输入非负总预算并确认
- **THEN** 系统保存该金额并在预算视图中展示

#### Scenario: 非法金额
- **WHEN** 用户输入负数或非数字金额
- **THEN** 系统拒绝保存并提示金额无效

### Requirement: 管理预算分项
系统 MUST 支持至少包含交通、住宿、餐饮、门票、其他的分项预算；用户可为各分项设定预算上限。

#### Scenario: 设置分项上限
- **WHEN** 用户为某一分项设定非负预算上限并保存
- **THEN** 预算视图显示该分项及其上限

### Requirement: 记录预估与实际支出
系统 MUST 允许用户为旅程添加支出记录，每条至少包含分项类别、金额、类型（预估或实际），可选备注。

#### Scenario: 添加实际支出
- **WHEN** 用户添加一条类别、金额有效且类型为实际的支出
- **THEN** 该记录出现在支出列表中，并计入实际合计

#### Scenario: 添加预估支出
- **WHEN** 用户添加一条类型为预估的支出
- **THEN** 该记录出现在支出列表中，并计入预估合计

### Requirement: 预算对比展示
系统 MUST 展示总预算、预估合计与实际合计的对比；当实际合计超过总预算时，MUST 给出超支提示。

#### Scenario: 未超支
- **WHEN** 实际合计小于或等于总预算
- **THEN** 系统展示对比数据且不显示超支状态

#### Scenario: 超支提示
- **WHEN** 实际合计大于总预算
- **THEN** 系统展示对比数据并明确提示已超支

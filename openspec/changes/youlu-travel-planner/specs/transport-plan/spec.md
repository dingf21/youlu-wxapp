# Spec Delta

## Purpose

按路段规划旅程交通方式、时间与关联地点，形成可执行的交通安排，并与预算分项衔接费用信息。

## ADDED Requirements

### Requirement: 添加交通路段
系统 MUST 允许用户为旅程添加交通路段，至少包含交通方式；可选出发地、到达地、出发时间、到达时间与预估费用。

#### Scenario: 创建完整路段
- **WHEN** 用户提交交通方式及可选的起终点与时间并确认
- **THEN** 系统保存该路段并在交通规划列表中展示

#### Scenario: 仅填交通方式
- **WHEN** 用户仅提交交通方式并确认
- **THEN** 系统仍保存该路段，未填字段以空值展示

### Requirement: 支持常见交通方式
系统 MUST 至少支持步行、公交、地铁、打车、自驾、火车、飞机、其他作为可选交通方式。

#### Scenario: 选择火车
- **WHEN** 用户创建路段并选择火车
- **THEN** 该路段以火车方式保存并可识别展示

### Requirement: 关联地点与日程
系统 MUST 允许将交通路段关联到旅程中的地点和/或某一天，以便在日行程中查看交通安排。

#### Scenario: 关联到某日
- **WHEN** 用户将某路段关联到旅程某一天
- **THEN** 该日视图中可看到该交通安排

### Requirement: 编辑与删除路段
系统 MUST 允许用户编辑已有路段字段或删除路段；变更 MUST 持久化。

#### Scenario: 修改时间
- **WHEN** 用户修改某路段的出发或到达时间并保存
- **THEN** 交通列表与已关联日视图显示新时间

#### Scenario: 删除路段
- **WHEN** 用户确认删除某路段
- **THEN** 该路段从交通列表及关联日视图中消失

### Requirement: 交通费用计入预算提示
当路段填写了预估费用时，系统 MUST 在交通或预算相关视图中提示该费用可计入交通分项（手动确认或一键带入均可，但 MUST 避免静默重复计入）。

#### Scenario: 有费用时提示
- **WHEN** 用户查看含预估费用的路段
- **THEN** 系统提示可将该费用纳入交通预算，且不会在无确认时自动重复记账
